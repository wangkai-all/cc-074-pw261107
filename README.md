# 数据集消费登记台

面向数据治理场景的单页演示应用：登记数据集字段、敏感级别、负责人与已批准的下游用途，
管理消费申请的提交 / 审批 / 撤销，生成可追踪的授权记录，并在字段或用途变化时驱动下游重新确认。

> 全部数据为**虚构目录**，保存在浏览器 localStorage，不连接任何真实权限系统。
> 顶栏可切换当前操作身份，用于演示「负责人审批」「负责人变更转交」等不同视角。

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
npm run smoke      # 核心业务规则冒烟测试（Node 驱动 store，34 项断言）
```

技术栈：React 19 + TypeScript + Vite（rolldown）+ 原生 CSS，无 UI 框架依赖。

## 页面与能力

| 页面 | 能力 |
| --- | --- |
| 数据集登记 | 数据集列表、风险概览（高敏字段 / 待确认授权 / 临期）、登记数据集、发起新消费申请、导出清单 |
| 数据集详情 | 字段增删改与敏感级别维护；查看使用中的报表/任务；本数据集的申请、授权与处理记录；负责人变更 |
| 消费申请审批 | 待我审批（按数据集负责人派生）、全部申请、重复申请合并视图；批准 / 驳回 / 撤回 |
| 授权台账 | 授权状态筛选、版本链追踪、撤销、到期重申、变更触发的重新确认、全量 CSV 导出 |
| 字段依赖视图 | 字段 → 授权 → 报表/任务的反向血缘，定位字段删改时受影响的消费方 |
| 目录管理 | 已批准用途目录（敏感级别上限、停用）、消费方（报表/任务）登记、虚构人员目录 |

## 核心业务规则（均在 `src/store.ts` 集中实现）

1. **申请即字段级**：申请必须选择具体字段与已批准用途；字段敏感级别超过用途上限直接拦截。
2. **批准生成授权**：审批通过后生成带编号、有效期、来源申请的授权记录，可全链路追踪。
3. **重复申请合并**：同数据集 + 同消费方 + 同字段集合 + 同用途视为重复，自动并入主单统一处理；
   但每条申请各自保留提交、合并、审批的完整处理记录。旧授权已到期/撤销时不再合并，需重新申请。
4. **变更必须重新确认，不沿用旧授权**：
   - 字段改名 / 改类型 / 敏感级别调整、字段软删除 → 引用该字段的生效授权全部转入「待重新确认」；
   - 用途敏感级别下调、用途停用 → 超出新约束的授权转入「待重新确认」；
   - 表名未变不构成沿用授权的理由。
5. **重新确认产生版本链**：确认通过后旧授权标记 `superseded`，生成新版本授权（`previousGrantId` 串链）；
   拒绝确认则按撤销处理。
6. **到期不可沿用**：到期状态由到期时间派生判定，到期授权不能继续使用，只能基于原范围提交全新申请。
7. **负责人变更自动转交**：待审批事项按数据集负责人实时派生，变更负责人即完成转交，并在每条待办上留痕。
8. **撤销留痕**：撤销授权同步更新来源申请状态，原因写入处理记录。

## 目录结构

```
src/
  types.ts            领域模型
  seed.ts             虚构目录种子数据（人员/数据集/字段/用途/消费方/申请/授权）
  store.ts            状态管理与全部业务规则（localStorage 持久化）
  labels.ts           状态/级别徽章字典
  styles.css          设计体系
  utils/              时间、敏感级别、CSV 导出
  components/         页面与弹窗（数据集、申请、授权、依赖、目录）
scripts/
  smoke.mjs           业务规则断言
  run-smoke.mjs       rolldown 打包并在 Node 执行冒烟测试
```

## 预置演示场景

- `ds4 商品维表` 的 `cost_price` 字段已发生口径变更，授权 `GR-202609-012` 处于待重新确认；
- `ds1` 下存在内容完全相同的重复申请（`APP-202611-001` / `APP-202611-002`）演示合并；
- `g5` 授权已到期，演示「不可沿用、到期重申」；
- 一条 L4 字段申请 L3 用途的记录（`APP-202610-006`）演示敏感级别拦截与驳回；
- 侧边栏「重置示例数据」可随时清空本地改动。
